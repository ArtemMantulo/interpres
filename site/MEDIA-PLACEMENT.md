# Media placement

All site media lives in `public/media/<page>/<block>/` and is copied into the build as-is.
Pages reference files as `media/<page>/<block>/<file>`. Files used on several pages are in `shared/`.
Unused files are kept in `../unused-media/` (outside `public/`, so they are not deployed).
